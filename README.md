### `01` — ShotgunKeyboard

**A Windows keyboard sound-feedback utility**

A desktop utility designed to play synthesized impact sounds when keys are pressed, with overlapping audio for fast typing.

- `PLATFORM:` Windows
- `FOCUS:` Python · Desktop development · Audio
- `GOAL:` Responsive sound feedback with configurable settings

[![Repository](https://img.shields.io/badge/VIEW_REPOSITORY-000000?style=for-the-badge&logo=github&logoColor=22C55E)](https://github.com/GURUMITHRAN-15/ShotgunKeyboard)

### `02` — chaos-engine

**A browser-based 3D game experiment**

An experimental browser game built around Three.js, with a focus on 3D driving mechanics and interactive gameplay.

- `PLATFORM:` Web browser
- `TECH:` JavaScript · Three.js · Vite
- `FOCUS:` 3D rendering · Controls · Game development

[![Repository](https://img.shields.io/badge/VIEW_REPOSITORY-000000?style=for-the-badge&logo=github&logoColor=22C55E)](https://github.com/GURUMITHRAN-15/chaos-engine)

### `03` — REFRIGUARD

**IoT-Based Refrigerator Monitoring and Alert System**

A college micro-project designed to monitor refrigerator temperature and door status using an ESP32 and provide alerts.

- `HARDWARE:` ESP32 · DS18B20 · OLED · Reed switch
- `FOCUS:` Embedded systems · Sensor monitoring · Alerts
- `OUTPUT:` Temperature readings and refrigerator door-status monitoring

### `04` — News Automation

**Automated news workflow using n8n**

An automation experiment focused on connecting workflow steps to process news-related information.

- `TECH:` n8n · Workflow automation
- `FOCUS:` Workflow design · Automation pipelines

### `05` — moviesda-mcp

An AI-powered tool project exploring integrations and developer tooling.
